## 🔐 Session Management

### Storage
- `sessionStorage` for current session (cleared on browser close)
- `localStorage` for "Remember me" (persistent across sessions)

### Keys Used
- `ehssuite_user` - Logged-in user email
- `ehssuite_remember` - Remember me flag
- `ehssuite_token` - Auth token (for backend)
- `ehssuite_dark_mode` - Dark mode preference

## 📞 Support & Troubleshooting

### Common Issues
- **Styles not loading**: Clear browser cache (Ctrl+Shift+Del)
- **Forms not validating**: Check browser console (F12)
- **Session not working**: Ensure localStorage is enabled
- **Redirect not working**: Verify all files in same directory

### Browser Console
- Check for JavaScript errors: Press F12 → Console tab
- See network requests: Network tab
- Inspect elements: Elements tab
